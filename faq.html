Frequently asked questions

A few useful answers before we begin.

If your question isn’t covered here, send us a message and we’ll help you work through it.

What does a website cost?

Website packages start at R1,150 once-off for the Starter Website. Basic is R2,500 and Premium is R3,750. Specialist work is quoted after the requirements are reviewed.

Can you redesign an existing website?

Yes. Website redesigns start from R500. Final pricing depends on the current website, the changes requested and any functionality involved.

Do you build custom web applications?

We can scope portals, dashboards, API integrations and other custom applications based on feasibility, requirements and third-party access.

Do you work with agencies?

Yes. White-label project builds, developer retainers and referral partnerships can be discussed. Confidentiality and scope are agreed before work begins.

Are domain and hosting included?

Do not assume domain, hosting, email or third-party fees are included in a package. The written quote will confirm exactly what is covered.

How do I request a quote?

Use the contact page to prepare an enquiry by email, or contact Zapify Designs directly through WhatsApp. Include your goals, required features and any deadlines.
